## 1. bds_ 파일 탐색 로직

작업 폴더에서 `bds_` 로 시작하고 `_prev` 로 끝나지 않는 파일을 탐색한다.
(`_prev` 파일은 백업본이므로 탐색 대상 제외)

탐색 결과에 따라 분기:

| 결과 | 동작 |
|------|------|
| **0개** | AskUserQuestion으로 세 가지 선택지 제시 (아래 참조) |
| **1개** | 파일 확인 없이 바로 로드 |
| **여러 개** | AskUserQuestion으로 선택 요청: 파일명을 선택지로 나열, 헤더 "스타일 파일이 여러 개 있어요" |

**0개 → AskUserQuestion 선택지:**
- **새로 만들기** → modules/create.md로 점프
- **다른 폴더에 있어요** → Other로 경로 입력받음 → 해당 경로에서 bds_ 탐색 후 진행
  - 해당 경로에서도 0개 → "그 폴더에도 없네요. 파일을 올려주시거나 새로 만들까요?" 한 번만 더 확인 후 종료
- **파일 올려줄게요** → 선택 후 "파일을 채팅창에 올려주세요, 읽고 바로 진행할게요" 안내 → 파일 업로드 대기 → 로드 후 진행

## 2. 디자인 어드바이스 평가

토큰 생성 또는 수정 후 **미리보기 렌더링 직전**에 내부적으로 색상 조합의 적절성을 평가한다.
별도 UI 없음 — 평가 결과는 미리보기 위젯 안에 함께 표시된다.

### 평가 기준

| 등급 | 기준 | 미리보기 위젯 처리 |
|------|------|------|
| ✅ 어울림 | 대비·채도·톤이 조화로움 | 일반 미리보기 렌더링 |
| ⚠️ 주의 | 가독성 저하 또는 충돌 가능성 있음 | 미리보기 상단에 경고 + 문제 토큰·대안값 표시 |
| 🚨 충돌 | 심각한 대비 부족 또는 색 충돌 | 미리보기 상단에 강조 경고 + 문제 토큰·대안값 표시 |

### 미리보기 위젯 내 어드바이스 영역 (⚠️/🚨 시)

```
┌─────────────────────────────────────────┐
│ ⚠️ 배경과 텍스트 대비가 낮아요           │
│  현재: Primary #XXX → 대안: #YYY        │
│  [현재 유지]    [제안으로 바꾸기]        │
├─────────────────────────────────────────┤
│  (일반 미리보기 — 컬러·타이포·컴포넌트) │
└─────────────────────────────────────────┘
```

- "현재 유지" → 미리보기 그대로 유지
- "제안으로 바꾸기" → 토큰 업데이트 후 미리보기 재렌더링
