# modules/update.md — 수정 플로우

> 전제: 파일은 이미 로드된 상태에서 시작. 별도 파일 탐색 불필요.
> 진입 경로:
>   - 진입점 ① B 흐름에서 bds_ 탐색 → 파일 선택 → 여기 진입
>   - modules/load.md (Type 1) 후 "수정할게요" 선택 → 여기 진입
>   - 생성(modules/create.md) 직후 "이거 바꾸고 싶어" → 여기 진입

---

## 수정 내용 확인

사용자가 요청한 변경 내용을 파악한다. 예:
- "메인 색을 좀 더 밝게 해줘"
- "폰트를 Pretendard로 바꿔줘"
- "다크 모드도 추가해줘"

---

## 버전 백업 (수정 전 실행)

현재 파일을 백업한 후 수정 진행:

1. 기존 `bds_[이름].md` → `bds_[이름]_prev.md`로 이름 변경
2. 수정된 내용으로 `bds_[이름].md` 새로 저장
3. 파일 헤더 버전 업 (예: 1.0 → 1.1)

> `_prev` 파일이 이미 있으면 덮어씀 (직전 버전 하나만 유지).

---

## 미리보기 & 최종 확인

1. **어드바이스 내부 평가** (modules/common.md 참조) — 렌더링 전 실행, UI 없음
2. **show_widget으로 미리보기 렌더링** (변경 전/후 비교 포함):
   - ✅ → 일반 미리보기
   - ⚠️/🚨 → 미리보기 상단에 경고 영역 포함 (문제 토큰 + 대안값 + 유지/교체 버튼)

"이렇게 바꿨어요. 더 수정할 곳 있으면 말씀해주세요."
- 추가 수정 있음 → 위 과정 반복 (단, 백업은 처음 한 번만)
- 없음 → 품질 체크 후 쇼케이스 제안

---

## 품질 체크 (수정 완료 직후)

최종 토큰 상태에서 아래 3가지를 내부적으로 체크한다. **수식 계산 없이 Claude 판단으로.**

**체크 항목:**
1. **명도 대비** — Primary 500이 흰 배경 위에서 읽히는가 (WCAG AA 4.5:1 기준)
2. **색 충돌** — Primary·Secondary·Accent 세 색이 서로 싸우거나 구분이 안 되는가 (셋 다 강한 보색이거나 셋 다 비슷한 색상)
3. **Neutral 이탈** — Brand 컬러 톤(웜/쿨)과 Neutral 100·900 방향이 정반대인가

**발동 조건:** 3개 중 **2개 이상** 걸릴 때만. 1개는 통과.

**출력:**
```
⚠️ 한 가지만요.
[문제 한 줄]
이대로 저장할까요, 아니면 한 번 손볼까요?
```

**반응별 처리:**
- "손봐줘" → 해당 항목만 수정 제안 후 재렌더링 → 쇼케이스 제안으로
- "그냥 써" → 군말 없이 쇼케이스 제안으로

---

## 쇼케이스 제안

수정 완료 후, 딱 한 번만 제안한다:

AskUserQuestion으로 선택지 제시:
- question: "수정된 디자인으로 쇼케이스도 만들어드릴까요?"
- 선택지:
  - **ShowCase A — 상세 가이드** — A4 가로 2페이지 HTML. 색상·타이포·토큰과 실사용 예시. PNG/PDF 저장 가능
  - **ShowCase B — 썸네일** — 680×680 카드 HTML. 색상 팔레트·폰트·버튼이 한눈에 보이는 미리보기 이미지
  - **둘 다** — ShowCase A + ShowCase B 순서로 생성
- Other 옵션: "괜찮아요" 등 거절 입력

실행 규칙:
- **ShowCase A** 선택 → `modules/showcase_a.md` 로드 후 실행 (bds_ 파일 탐색 불필요 — 방금 저장한 파일 사용)
- **ShowCase B** 선택 → `modules/thumbnail.md` 로드 후 실행 (동일)
- **둘 다** 선택 → showcase_a.md 실행 완료 후 → thumbnail.md 실행
- **거절** → 종료. "나중에 '썸네일 만들어줘' 또는 '쇼케이스 만들어줘'로 언제든 요청할 수 있어요." 짧게 안내.

## "이전으로 돌려줘" 요청 시

`_prev` 파일 존재 여부 확인:
- **없음** → "아직 수정 이력이 없어서 되돌릴 버전이 없어요." 안내 후 종료
- **있음** → AskUserQuestion으로 확인:
  - 선택지: "네, 되돌려줘" / "아니요, 현재 버전 유지"
  - 확인 후 복원: `bds_[이름]_prev.md` → `bds_[이름].md`로 복원
  - 복원 완료 후 `_prev` 파일은 삭제
