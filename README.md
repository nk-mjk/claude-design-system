# 🎨 design-system-by-blue — 나만의 디자인 스타일 관리 스킬

> 내 색깔·폰트·분위기를 파일 하나에 저장해두고, PPT·문서·위젯을 만들 때마다 일관된 디자인으로 자동 적용하는 Claude Cowork 스킬

📖 **『클로드 디자인 시작하기 - 퇴근은 내가! 야근은 AI가!』 독자 전용 스킬**
업데이트 정보 → [vielbooks.com](https://vielbooks.com/) | 유튜브 → [@mjKorea123](https://www.youtube.com/@mjKorea123)

## 이게 뭔가요?

PPT 만들 때마다 색이 달라지고, 문서마다 폰트가 제각각이라면 — 이 스킬이 그 문제를 해결해줍니다.

내 브랜드 색깔·폰트·분위기를 한 번만 설정해두면(`bds_` 파일로 저장), 이후 PPT·문서·카드뉴스·위젯을 만들 때마다 "내 스타일로 해줘" 한 마디로 일관된 디자인이 나와요.

Claude Design에서 만든 디자인 시스템 파일(.zip)을 그대로 불러올 수도 있어요.

---

## 주요 기능

### 🗂️ 스타일 관리 (생성·수정·불러오기)
- 색깔·폰트·분위기를 대화로 설정해서 `bds_` 파일로 저장
- 기존 파일 수정 시 자동 백업 (직전 버전 1개 유지)
- Claude Design 패키지(.zip) 직접 불러오기 지원

### 🖌️ 디자인 적용
- 저장된 스타일을 PPT·문서·위젯에 바로 적용
- 같은 대화에서 방금 만든 스타일은 재질문 없이 자동 적용

## 스타일 파일(bds_) 구조

한 번 만들어두면 이런 파일이 저장됩니다.

```
bds_mybrand.md      ← 현재 버전 (내 디자인 스타일)
bds_mybrand_prev.md ← 직전 버전 (수정 전 백업)
```

이 파일만 있으면 어느 대화에서든 불러서 바로 쓸 수 있어요.
